A full-stack task management system built using Node.js, Express, MongoDB, React, Vite, and Tailwind CSS, designed to support team-based workflows with role-based access control.

The application features JWT-based authentication with admin and member roles, allowing secure task creation, assignment, and tracking across multiple users. Tasks support advanced statuses such as Pending, In Progress, Completed, Overdue, and Blocked, along with todo checklists that track progress in real time.

A comprehensive Activity Log (audit trail) automatically records all task-related actions—including creation, updates, status changes, checklist toggles, and deletions—displayed chronologically on the task details page with user and timestamp information.

The system also includes an admin dashboard with visual analytics (pie and bar charts), Excel report generation for tasks and users, and user management with dependency validation to prevent data inconsistencies. The frontend delivers a fully responsive UI with role-based rendering to ensure a clear and secure user experience across devices.
